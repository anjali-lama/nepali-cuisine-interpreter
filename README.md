# 🍜 Nepali Cuisine Interpreter

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![Flask](https://img.shields.io/badge/Flask-2.3.3-green.svg)](https://flask.palletsprojects.com/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

An AI-powered web application that translates, interprets, and provides cultural insights about Nepali cuisine. The system uses three machine learning models to accurately identify and contextualize Nepali dishes.

![Nepali Cuisine Interpreter Screenshot](https://via.placeholder.com/800x400/20b2aa/ffffff?text=Nepali+Cuisine+Interpreter)

## ✨ Features

### 🤖 **Multi-Model AI Analysis**
- **Rule-Based Model** (80% accuracy): Pattern matching with predefined rules
- **TF-IDF Vectorizer** (90% accuracy): Statistical text analysis for semantic understanding  
- **Ensemble Model** (90% accuracy): Combined approach for optimal results

### 🌍 **Cultural Intelligence**
- **Did You Know?** facts about each dish's history and traditions
- **Phonetic pronunciations** to help users say food names correctly
- **Dietary information** including vegetarian status and spice levels
- **Preparation time** estimates for each dish

### 🎨 **User Experience**
- **Beautiful mint green theme** with clean, professional design
- **Responsive layout** that works on desktop and mobile
- **Quick search buttons** for popular Nepali foods
- **Interactive popups** with cultural insights
- **Model evaluation dashboard** with accuracy metrics

## 📊 Dataset

The application uses a comprehensive dataset of **100+ authentic Nepali dishes** with:
- Nepali names in Devanagari script
- Romanized names for easy searching
- English descriptions with cultural context  
- Phonetic pronunciation guides
- Interesting facts and traditions
