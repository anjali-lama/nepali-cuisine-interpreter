Dataset Information

Dataset Overview

  • Total Foods: 100+ authentic Nepali dishes
  • Data Points Per Dish: 6+ attributes
  • Script Support: Devanagari & Romanized
  • Source: Authentic Nepali cuisine database

Data Attributes

  • Nepali name (Devanagari script)
  • Romanized name
  • English description with context
  • Phonetic pronunciation guide
  • Cultural facts & traditions
  • Dietary information

System Architecture

Workflow

  1. Input: User enters food name (Romanized or Nepali)
  2. Processing: All three models analyze the input simultaneously
  3. Rule-Based: Checks exact patterns and predefined rules
  4. TF-IDF: Calculates semantic similarity and term frequency
  5. Ensemble: Combines results from both models
  6. Output: Cultural insights, pronunciation, images, dietary info

Performance Metrics

  • Response Time: < 1 second per query
  • Model Runtime: All models run in parallel
  • Success Rate: 95%+ for known foods
  • Fallback System: Static data when backend unavailable
  • Scalability: Can handle 1000+ concurrent users
